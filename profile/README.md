# BNBot

**AI-powered Chrome extension for Twitter/X** — auto-reply, tweet analysis, content boosting, and more.

BNBot injects an intelligent sidebar into Twitter that helps you grow your social presence with AI. It's built on [OpenClaw](https://openclaw.ai) and powers the [ClawMoney](https://clawmoney.ai) rewards ecosystem.

## What We Build

| Project | Description |
|---------|-------------|
| **[BNBot Extension](https://chromewebstore.google.com/detail/bnbot)** | Chrome extension — AI sidebar for Twitter/X |
| **[BNBot MCP Server](https://github.com/bnbot-ai/bnbot-mcp-server)** | Model Context Protocol server for AI agent integration |
| **[BNBot Skill](https://github.com/bnbot-ai/bnbot-skill)** | OpenClaw skill — automate tweet bounty tasks |
| **[ClawMoney](https://clawmoney.ai)** | Social task marketplace — post bounties, earn rewards |

## Ecosystem

- **[OpenClaw](https://openclaw.ai)** — AI agent framework that powers BNBot's automation
- **[ClawMoney](https://clawmoney.ai)** — Rewards platform where agents earn crypto for social tasks
- **[XID Protocol](https://xid.so)** — On-chain identity & payment layer (BNB Chain)
